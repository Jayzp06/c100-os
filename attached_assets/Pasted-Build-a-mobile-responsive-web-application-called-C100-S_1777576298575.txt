Build a mobile-responsive web application called “C100 System” for the Fort Valley State University Trailblazing Chapter of Collegiate 100.

This is NOT a social media app. It is a performance, accountability, attendance, committee, and development platform for Collegiate 100 chapters.

The platform should help the chapter track participation, committee activity, member growth, event attendance, scholarship eligibility, conference selection eligibility, and end-of-semester recognition.

Use a clean, modern, professional design. The system should feel like a private chapter operating system.

CORE PURPOSE:
The chapter struggles with member retention and inconsistent engagement. Members often show up during hype moments but fall off over time. This system should make consistency feel rewarding, visible, and accountable.

The app should support:
- Member login
- Committee assignment
- Event creation
- Dynamic QR attendance
- Participation tracking
- Committee rankings
- Private individual performance tracking for leadership
- Basic automated nudges
- End-of-semester award and conference eligibility logic

IMPORTANT ORGANIZATIONAL CONTEXT:
The system aligns with Collegiate 100’s Four for the Future framework:
1. Mentoring
2. Education
3. Economic Development
4. Health & Wellness

Also include a Bylaws Chair role.

USER ROLES:
Create role-based dashboards for:
1. Member
2. Committee Chair
3. Bylaws Chair
4. Executive Board
5. Admin

ROLE ACCESS:
Member:
- Can view personal dashboard
- Can see their committee
- Can view upcoming events
- Can scan/check into events
- Can view their own participation percentage
- Can view their private points total
- Can view public committee leaderboard
- Can view personal nudges

Committee Chair:
- Everything a member can do
- Can create committee events
- Can activate QR check-in
- Can view private roster for their committee
- Can view member participation inside their committee
- Can receive chair-specific alerts

Bylaws Chair:
- Everything a member can do
- Has a placeholder section for bylaws reference tools
- Can later help draft amendment proposals

Executive Board:
- Can view all member scores privately
- Can view committee health
- Can view nudge logs
- Can view scholarship and conference eligibility reports

Admin:
- Full system access
- Can manage users
- Can assign roles
- Can assign committees
- Can create, edit, approve, cancel events
- Can manually correct attendance with a reason
- Can suspend accounts

MAIN DASHBOARD REQUIREMENTS:
When a member logs in, the first thing they should see:
1. Their committee
2. Their upcoming events
3. Their participation percentage toward the 75% requirement
4. Their private point total
5. Any active nudge
6. Public committee leaderboard

Do NOT show public individual rankings. Members should not see other members ranked by name. Public competition should only be committee-based.

QR ATTENDANCE:
Build a dynamic QR attendance system.

Flow:
1. Chair or Admin opens an event
2. Chair/Admin activates check-in
3. System generates a QR code
4. QR code rotates every 60 seconds
5. Member scans QR code while logged in
6. System validates:
   - user is authenticated
   - event is active
   - QR token is valid
   - check-in is within the allowed time window
   - user has not already checked into the same event
7. Attendance is recorded
8. Member’s points update
9. Committee score updates
10. Member receives confirmation

Include:
- Duplicate scan prevention
- Manual override by Admin with correction reason
- Attendance timestamp
- Attendance method: QR Scan, Manual, Corrected

Do NOT rely on GPS for MVP. Location verification may be added later, but Version 1 should use dynamic QR codes.

MEMBER SCORING:
Track:
- Attendance count
- Participation percentage
- Total points
- Streak count
- Impact points
- Committee contribution
- Nudge status

Participation percentage should compare attended eligible events against total eligible events.

NUDGE SYSTEM:
Create basic automated nudge logic.

Nudge tiers:
Active:
- 75% participation or higher
- No warning nudge
- If 5+ event streak, send encouragement

Warning:
- 60–74% participation
- Send gentle reminder

At-Risk:
- 40–59% participation OR missed 2+ consecutive events
- Send stronger warning
- Notify committee chair

Critical:
- Below 40% OR missed 4+ consecutive events
- Send urgent alert
- Notify Executive Board

Chair alerts:
- If no committee event scheduled in 21 days, alert chair
- If committee participation drops below 60%, alert chair
- If committee drops below 50%, notify Executive Board

Example nudge messages:
Active streak:
“You’ve attended 5 events in a row — that’s the kind of consistency that defines a leader. Keep it up.”

Warning:
“Your participation is currently at [X]%, below the 75% requirement. Attend [X] more events to get back on track.”

At-Risk:
“You’ve missed multiple events and your active membership status may be affected. Attend the next event to reset your progress.”

Critical:
“Your participation is significantly below the required standard and has been flagged for Executive Board review.”

Chair no event:
“Your committee has no upcoming events scheduled. Please create and publish your next event.”

REWARD SYSTEM:
End-of-semester only. No point store. No frequent rewards.

Awards:
1. Top Committee
2. Top Committee Chair
3. Top Contributor per Committee
4. Rising Member
5. Major Scholarship

Scholarship eligibility:
- Active membership
- Dues paid
- Minimum 75% participation
- GPA at or above 2.7
- No active code of ethics violations
- 80% system performance score
- 20% Executive Board review

Conference eligibility:
- Top tier system score
- Minimum 75% participation
- Strong impact score
- Dues paid
- No code of ethics violation
- GPA at or above 2.7
- Final decision uses 80% system data and 20% leadership review
